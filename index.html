📊 Visual Architecture & Memory Learning

Visual learning blueprints illustrating low-level CLR memory models, B-Tree index lookups, ASP.NET Core middleware pipelines, and React Fiber double-buffering.

CLR Internals

1. .NET Memory Architecture: Stack vs. Gen 0/1/2 Ephemeral Heaps vs. LOH & POH

Visual breakdown of memory allocation in the CLR. Local variables and Span<T> (ref structs) live strictly on the execution thread stack with zero GC cost. Managed objects live on the Ephemeral GC Heaps (Gen 0, 1, 2) where compaction relocates memory, while large arrays (≥85KB) allocate directly on the LOH (not compacted by default) and pinned buffers allocate on the POH.

Stack: Fast thread-local, ref struct zero allocation
Gen 0/1/2: Ephemeral segmented generational collection
LOH: ≥85KB large objects avoiding compaction overhead
POH: Pinned socket/native memory buffers
SQL Server

2. SQL Server B-Tree Index Seek vs. Key Lookup vs. Covering Index (INCLUDE)

Physical layout of SQL Server indexes. When a query filters on an indexed column, SQL Server navigates the B-Tree from the Root Node down to Leaf pages (Index Seek: O(log N)). If the query selects columns not present in the index leaf, it performs expensive nested loop Key Lookups. Adding leaf-level payload columns with INCLUDE creates a Covering Index, completely bypassing base table roundtrips.

ASP.NET Core

3. ASP.NET Core Russian Doll Middleware Pipeline

Execution flow of an HTTP request through ASP.NET Core middleware. Middleware wraps subsequent components like Russian nesting dolls (RequestDelegate next). Requests travel inward through Exception Handling, HSTS, Routing, Rate Limiting, Authentication, and Authorization to the Endpoint Handler, then unwind outward in reverse order.

React 19 & TS

4. React Fiber Architecture: Double Buffering & Lane Scheduler

React's reconciler manages two fiber trees simultaneously: the current tree (mounted on screen) and the workInProgress tree (built asynchronously offscreen in the interruptible render phase). When reconciliation completes, React flips a single root pointer in the synchronous commit phase for flicker-free UI rendering.
